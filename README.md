# Saikiran Pasunuti — Portfolio

A responsive engineering portfolio covering full stack development, search, business automation, and the Autoverse AI LLM workflow.

## Files

- `index.html` — the complete portfolio, with CSS, JavaScript, favicon, and downloadable résumé embedded. No build step or dependencies.
- `Saikiran_Pasunuti_Resume.pdf` — the current two-page résumé.

## Preview locally

Open `index.html` in a browser, or serve this directory with any static HTTP server.

## Deploy

Publish the repository root with a static hosting provider. For GitHub Pages, choose **Settings → Pages → Deploy from a branch → main → / (root)** and save. No build command is required.

## Maintain

Edit the styles in `<style>` and interactions in `<script>`. Keep the résumé download in `index.html` synchronized when replacing the PDF. The `resume` link stores the PDF as a base64 data URL.
